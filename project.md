# Семейные Расстановки — Project Overview

## Что это за проект

Личный сайт-проект Нязик Тач под брендом **«Семейные Расстановки»**.
Сайт объединяет точки входа для новых клиентов: лендинг с описанием метода,
цифровую визитку с контактами, страницу записи, блог и страницу «Обо мне».
Весь контент ориентирован на русскоязычную аудиторию.

## Для кого

Женщины, которые чувствуют усталость, тревогу, потерю себя, сложные отношения
или боль, которую трудно объяснить. Люди, которые хотят работать не с симптомом,
а с глубинной причиной.

## Страницы, которые уже есть

| Файл | Описание |
|------|----------|
| `landing.html` | Лендинг продукта «Системные расстановки» — описание метода, 3 преимущества, блок «для кого», CTA-кнопка «Записаться на сессию» |
| `vizitka.html` | Цифровая визитка — имя, специализация, короткое био, иконки соцсетей (Telegram, Instagram, WhatsApp, YouTube), кнопка «Написать мне» |

Дополнительно в проекте есть отдельное React-приложение `stories-reels-generator/` —
генератор идей для Reels и Stories на базе Vite + Tailwind CSS.

## Страницы, которые планируются

| Страница | Содержание |
|----------|------------|
| `about.html` | «Обо мне» — фото, история, образование, подход к работе |
| `booking.html` | Запись на сессию — форма или прямая кнопка в Telegram |
| `blog/` | Блог — статьи о расстановках (отдельные HTML-файлы или папка) |

**Отзывы** будут размещены прямо на `landing.html`, отдельной страницы не нужно.

## Стиль дизайна

- **Фон:** почти чёрный (`#07070d`), тёмные карточки (`#0f0f16`)
- **Акцентный градиент:** фиолетовый → индиго → голубой (`#e879f9 → #a5b4fc → #7dd3fc`)
- **Типографика:** системный шрифт (`-apple-system`, `BlinkMacSystemFont`), крупные жирные заголовки
- **Анимации:** дрейфующие blob-ы на фоне, плавающие частицы, shimmer на заголовках, пульсирующий CTA
- **Карточки:** тёмные с тонкой границей, hover-эффект с подъёмом и фиолетовым свечением
- **Адаптивность:** полностью мобильная вёрстка, breakpoints на 480px и 720px
- **Зависимости:** нет — всё в одном HTML-файле, чистый CSS + Vanilla JS
