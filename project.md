# ANNE Healing Blog — Project Overview

## Что это за проект

Личный сайт Нязик Тач — практика семейных расстановок.
Проект объединяет лендинг с описанием метода, цифровую визитку с контактами
и инструменты для продвижения в социальных сетях.
Весь контент на русском языке, аудитория — русскоязычные женщины 30–55 лет.

---

## Для кого

Женщины, которые чувствуют усталость, тревогу, потерю себя, сложности в отношениях
или боль, которую трудно объяснить словами. Люди, которые хотят работать не с симптомом,
а с глубинной причиной через метод системных расстановок.

## Стиль дизайна

**Цвета**
- Фон: `#0a0a0a` / `#07070d` — почти чёрный
- Карточки: `#0f0f13` / `#13131c` — тёмно-серые поверхности
- Акцентный градиент: фиолетовый → индиго → голубой (`#e879f9 → #a5b4fc → #7dd3fc`)
- Muted-текст: `#94a3b8`

**Типографика**
- Системный стек: `-apple-system, BlinkMacSystemFont, 'Segoe UI', system-ui`
- Заголовки: крупные, жирные, с gradient-text эффектом
- Капслок + letter-spacing для подзаголовков и лейблов

**Анимации**
- Фоновые blob-ы (дрейфующие размытые пятна)
- Плавающие частицы (Vanilla JS)
- Shimmer на заголовках
- Пульсирующая аура на CTA-кнопке
- 3D-наклон карточки за курсором (desktop only)
- Reveal-анимация при скролле (IntersectionObserver)

**Принципы вёрстки**
- Полностью адаптивная (мобильный breakpoint 480px, средний 720px)
- HTML-страницы: без внешних зависимостей, всё в одном файле (CSS + SVG + Vanilla JS)
- Generator-приложение: React + Tailwind CSS, собирается через Vite
