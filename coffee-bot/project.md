# Паспорт проекта: Telegram-бот «Утренний кофе»

---

## Название проекта

**Telegram-бот для кофейни «Утренний кофе»**

---

## Что это

Telegram-бот для предзаказа кофе и десертов с самовывозом. Клиент делает заказ со смартфона по дороге на работу, указывает время — и приходит к готовому напитку без очереди. Бот работает внутри Telegram: не нужно скачивать отдельное приложение. Для владельца — это инструмент управления заказами и база постоянных клиентов.

---

## Для кого

**Основная аудитория:** жители района 20–45 лет, которые заходят за кофе каждое утро по дороге в офис или на учёбу.

Им важно:
- не стоять в очереди — каждая минута утром на счету
- знать точное время готовности, а не «минут через 15»
- забрать и уйти — без разговоров, без ожидания

**Вторичная аудитория:** постоянные гости в течение дня, которые хотят удобно повторить любимый заказ.

---

## Какую проблему решает

Утром у кофейни очередь. Человек спешит на работу, видит очередь — и проходит мимо. Кофейня теряет клиента и выручку.

Для клиента: потерянное время и раздражение.  
Для владельца: потерянная продажа и клиент, который привык к другому месту.

Бот убирает очередь из уравнения: заказ сделан в метро, кофе готов к приходу.

---

## MVP — что делаем первым

Только то, без чего бот не работает:

| # | Функция | Зачем |
|---|---|---|
| 1 | Меню с категориями и ценами | Клиент видит что заказать |
| 2 | Корзина и оформление заказа | Клиент собирает и подтверждает заказ |
| 3 | Выбор времени самовывоза | Бариста знает к какому времени готовить |
| 4 | Уведомление клиенту | «Принят» → «Готов» — без тревоги и звонков |
| 5 | Уведомление баристе в Telegram-группу | Заказ виден персоналу без лишних сервисов |
| 6 | Панель владельца в боте | Включить/выключить приём, посмотреть заказы |
| 7 | Управление меню через бота | Изменить цену или убрать позицию без разработчика |

**Оплата на старте:** наличными или картой при получении. Онлайн-оплата — этап 2.

---

## Функции на будущее

**Этап 2 — Лояльность**
- Каждый 5-й кофе бесплатно (счётчик виден в боте)
- Прогресс «до следующей награды — 2 кофе» мотивирует вернуться
- Предоплаченные пакеты: 10 кофе по цене 8

**Этап 3 — Монетизация и акции**
- Комбо-предложения с ограниченным сроком («Американо + круассан = 350 ₽ по пятницам»)
- Push-уведомления об акциях подписчикам (только тем, кто согласился)
- Подарочные сертификаты через бота

**Этап 4 — Онлайн-оплата**
- ЮKassa через Telegram Payments — оплата внутри чата без перехода в браузер
- Требует ИП/ООО и ~7 дней на подключение

**Этап 5 — Аналитика**
- Популярные позиции, часы пик, средний чек, выручка за период
- Сегментация: кто ходит каждый день, кто давно не приходил

## Технологии

| Компонент | Выбор | Почему |
|---|---|---|
| Платформа | Telegram Bot API | Нулевой порог входа для клиента |
| Язык | Python | Большое сообщество, много готовых примеров |
| Фреймворк | aiogram 3 | Async, встроенная FSM, лучший выбор для сложных флоу |
| База данных | SQLite → PostgreSQL | SQLite на старте (ноль настройки), PostgreSQL при росте |
| Хостинг | Timeweb VPS (~200 ₽/мес) | Оплата рублями, поддержка по-русски, надёжный uptime |
| Платежи | ЮKassa + Telegram Payments | Стандарт в России, оплата внутри Telegram |
| Уведомления | Telegram-группа персонала | Нулевая стоимость, все видят заказы на телефоне |
| Admin-панель | Команды в боте → позже Flask | Быстро на старте, веб-интерфейс добавим при необходимости |

**Ориентировочная стоимость инфраструктуры: 200–400 ₽/мес** (без учёта комиссии ЮKassa — 2,8–3,5% с транзакции).

## Первые шаги

1. **Проверить гипотезу** — опросить 5–10 постоянных клиентов: воспользовались бы ботом? Что важно?
2. **Сравнить с Кафеботумом** — зарегистрироваться на бесплатном тарифе, настроить меню, дать нескольким клиентам попробовать. Если устраивает — не писать с нуля.
3. **Если кастом** — создать бота через BotFather, получить токен.
4. **Настроить окружение** — Python 3.11+, aiogram 3, aiogram-dialog, aiosqlite.
5. **Написать меню** — собрать все позиции, цены, категории в формат для базы данных.
6. **Сделать базовый флоу** — /start → категории → позиция → корзина → время → подтверждение.
7. **Подключить уведомления** — создать закрытую Telegram-группу для персонала, бот пишет туда.
8. **Тест с реальными клиентами** — запустить на 2–3 недели, собрать обратную связь.
9. **Подключить ЮKassa** — когда базовый флоу стабилен (нужны ИП/ООО и ~7 дней на верификацию).

## Риски

| Риск | Вероятность | Как снизить |
|---|---|---|
| Клиенты не пользуются ботом | Средняя | QR на кассе + скидка на первый заказ через бот |
| Бот ломается в часы пик | Низкая | Мониторинг, VPS с нормальным uptime |
| Меню не совпадает с реальностью | Высокая | Обновлять меню сразу при изменениях, добавить стоп-лист |
| Персонал игнорирует уведомления | Средняя | Обучение + звуковые уведомления в группе |
| ЮKassa не подключается вовремя | Средняя | Стартовать без онлайн-оплаты, добавить позже |
